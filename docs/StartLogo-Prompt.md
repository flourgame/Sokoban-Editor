# 开始界面 Logo 生图提示词

视觉参考：活泼、错落、圆润的粗体字形，加上本项目箱子原图 `Assets/Resources/img/Box.png`。游戏名称沿用「推箱子」。

## 提示词

为休闲解谜游戏「推箱子」设计一个完整、独立的游戏标题 Logo，透明背景 PNG，横向构图，2048×1024。画面唯一文字是中文「推箱子」，三个字准确、完整、清晰可读，无副标题、英文、标语或水印。

字形参考所附活泼文字 Logo：圆润饱满的超粗展示字体，字的大小和基线轻微错落，带自然的小角度旋转，有弹跳感和轻松有趣的气质；整体仍紧凑、平衡，轮廓一眼可辨。采用简洁的二维游戏插画与略带像素切角的复古街机质感，干净利落，使用克制的厚描边和短距离层叠投影。

配合游戏的深青灰油彩流动背景：主色为暖白 #F2EADF、暖铜 #D5A86E，辅以低饱和青绿 #5C8A86，描边及投影使用深青灰 #1C3034。明亮主体与深色背景要有足够区分度，呈现温暖、复古、精致的小游戏气质。

必须融入第二张参考素材中的木箱：保留它金棕色的圆角方形外轮廓、上部斜木板、下部深棕色横向凹槽和原有明暗层次，不能换成普通纸箱、宝箱或另一种木箱。将木箱作为 Logo 的视觉核心，与「箱」字的中下部自然叠放或嵌合，轻微倾斜，保持三个汉字都能完整辨认。可添加极少量小方块或短箭头，暗示推动与移动，装饰不抢过标题和木箱。

只绘制 Logo 本身，周围保留约 8%–10% 的透明安全边距，主体尽量占满横向空间。不要绘制完整游戏界面、按钮、场景背景、棋盘、扑克、扑克牌花色、人物或软件图标；不复制参考图中的文字，不加入 CRT 扫描线、屏幕弯曲、模糊和强发光。输出边缘干净、无白底的透明 PNG。

## 接入位置

生成的 Logo 放在 `Assets/Resources/StartLogo.png`，并以 Sprite (2D and UI) 导入。开始界面优先读取该资源，也兼容原定的 `Assets/Resources/UI/StartLogo.png` 路径。新 Logo 已包含木箱，加载后会自动撤掉旧 Logo 和临时叠放的木箱。
