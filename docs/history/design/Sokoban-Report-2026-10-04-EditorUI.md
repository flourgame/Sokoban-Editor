## 3. UI 重叠与配色的修法

根因：旧布局用"相对父级中心的绝对偏移"硬编码，而面板几乎铺满全屏，导致标题压面板、列表头压首项、返回键压面板底，且换分辨率会更糟。

修法：在 `SokobanSceneController` 基类引入边缘锚定三段式布局——顶部标题带（TopTitle/TopSubtitle）、中部内容带（InsetPanel 四周留白）、底部按钮带（ButtonAt 锚边角）；面板内栏目标题用 PanelHeader、滚动列表锚其下方。四个界面全部改用该套辅助方法，重叠在结构上不再可能发生，且分辨率无关。

配色：新增 `SokobanTheme` 统一色板（深蓝灰底 + 石板灰面板 + 琥珀主按钮 + 青蓝玩家色），按钮/输入框/列表/棋盘格子全部取色于色板。

## 4. 编辑器重构要点

新文件 `Assets/game_script/SokobanEditorController.cs`，旧编辑器控制器已从 `SokobanSceneControllers.cs` 移除，bootstrap 改指向新控制器。

- 数据模型：`SokobanEditorTab`（descriptor + data + dirty + 撤销栈）；剪贴板为相对偏移 + 格子内容，支持不相邻多选。
- 工具栏：箱子/玩家/墙面/目标/地面 + 复制/粘贴/填充/印章（占位）。
- 页签栏：多文档，脏标记 "*"，× 关闭，+ 新建。
- 编辑区：视口 RectMask2D + 可平移缩放内容层；鼠标→格子统一映射；hover 虚影；左键落笔；拖拽框选显示蓝色虚线 + 半透明蓝填充选区框；Ctrl 多选；选中格蓝色虚线边框（运行时 tiled 虚线 sprite 四边拼接）；中键平移；Ctrl+滚轮缩放 0.5x–2.5x。
- 复制/粘贴/填充：Ctrl+C 复制选中为相对模式；Ctrl+V 进入粘贴模式虚影跟随、左键落位、Esc 取消；填充对全部选中格落当前笔刷。
- 撤销：每页签独立栈，变更前对 `SokobanJsonLevel` 深拷贝入栈（上限 100），覆盖落笔/填充/粘贴/改尺寸等全部变更入口；Ctrl+Z 弹栈恢复。
- 右栏：名称、长×宽（改尺寸并裁剪越界实体）、详情显示区、试玩（先写入再进 game）、验证、复制json（系统剪贴板）、写入（保存）、导出（另存新关卡并开新页签）；自动生成占位。

## 5. 本轮发现并修复的隐藏 bug

1. 主标题不显示：`SokobanUI.Text` 设 `verticalOverflow=Truncate`，标题框高 72 < 字号 76，整行被裁。改为框高随字号自适应。
2. 次级按钮近黑：`Button` 的 `ColorBlock` 各色与图像色相乘，旧代码把 normalColor 设成图像色导致平方压暗。改为 normal=白 + 相对明暗 tint。
3. 棋盘/编辑网格偏左：`GridLayoutGroup` 默认 UpperLeft。加 `childAlignment=MiddleCenter`。
4. 几十条 "2 event systems" 警告：level/editor 场景烘焙了 EventSystem，运行时又建 DontDestroyOnLoad 实例。改为场景级、不持久。
5. 工具栏/页签按钮文字不显示：同为 Truncate 陷阱——STXIHEI 在 24px 下行高约 32，按钮框高只有 32/26，首行放不下被裁成 0 顶点。按钮标签改用 `Overflow` 并加高按钮。
6. 页签 × 偏移：小按钮上 `SokobanUI.Text` 默认 12/4 内边距占比过大挤偏字形。关闭按钮 Label 改全出血居中。
7. 选区虚线散乱：旧实现手算四边坐标出错。改为"容器 + 四边 stretch 虚线"，不再手算。
8. 选区边框/框选框完全不显示：选区覆盖层与选区框是编辑内容层的早兄弟，而格子后创建、画在其上，虚线被格子图像盖住（早期"散落竖线"正是虚线从格子缝隙漏出的部分）。修复：`RebuildGrid` 末尾与创建选区框后调用 `SetAsLastSibling()`，确保覆盖层始终在最上层。
