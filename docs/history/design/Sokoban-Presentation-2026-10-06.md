# 普通玩家视听表现修复与调色（2026-10-06）

本轮覆盖主菜单、选关、关卡、暂停、地图、设置和场景转场。保留推箱子项目的玩家、箱子、墙、地板和目标图案；不修改关卡编辑器界面及 Balatro 安装目录。

## 动画修复

原预制体的图片与移动坐标共用根 RectTransform，图片抖动协程会不断恢复根对象的初始位置，导致逻辑格与画面错位。现在玩家和箱子预制体都采用 `实体根 / Body`：根只负责格子移动，Body 只负责抖动和压缩展开。预制体 GUID 和贴图引用保留，烘焙工具也采用同样结构。

连续输入和中途撤销从当前画面位置继续补间；相同状态刷新不重置移动；重开立即取消旧的图片动效。窗口尺寸变化只按格距缩放补间源点和目标。箱子先匹配保持原位的实例，再匹配被推动的实例，避免箱子集合顺序导致交换身份。

列表和普通按钮同样采用独立 `ButtonVisual`，布局根的位置和尺寸始终由原布局管理，悬停的轻抖与浮起、点击下沉都发生在图片子层。

## 转场

常驻转场宿主保持激活，仅隐藏遮罩图片。离场用 0.34 秒缩小圆形开口直到全黑；新场景完成 Start 和布局后，用 0.56 秒扩大开口揭示画面。首次打开普通玩家场景也播放入场。改用普通帧等待，避免 Unity 游戏视图失去焦点时 `WaitForEndOfFrame` 阻塞。

## Balatro 资源接入

背景使用原版 `background.fs` 的五轮油彩迭代与混色公式移植到 HLSL。修复 Workspace 实色背景覆盖动态背景的问题。

面板直接使用原版 `Enhancers.png` 的空白卡框；按钮轮廓按原版 `engine/ui.lua` 的像素顶点生成九宫格遮罩，配合浮雕阴影。筹码、沙漏、Logo 与音频使用提取出的原图及原片段。原版按钮并非独立 PNG；来源与移植方式见 [归属说明](../../../Assets/ThirdParty/Balatro/Attribution.md)。

## 新配色与关卡文字

开始界面按用户参考改为上方大 Logo、底部横向按钮栏，仅显示「开始游戏 / 设置 / 退出」。移除旧的隐藏标题、副标题与操作说明，开始按钮加宽，三个按钮分别采用暖铜、青绿与低饱和珊瑚红。临时 Logo 使用现有 Balatro 字样与原项目木箱组合。后续导入 `Resources/UI/StartLogo` 精灵即可整体替换并自动去掉临时木箱；生图提示词见 `docs/StartLogo-Prompt.md`。已核对 1920×1080 运行截图与开始/设置/返回流程，截图为 `docs/verification/presentation/start-horizontal-menu.png`。

普通玩家界面统一为深青灰、暖铜色与低饱和珊瑚红：面板 `#1C3034`、边框 `#5C8A86`、主按钮和选中项 `#D5A86E`、正文 `#F2EADF`、辅助文字 `#B9CEC7`。背景由青色、铜红和深灰组成，降低亮度。棋盘原图仅施加轻微统一色温，保持图案及实体辨识。

关卡顶部新增深色衬底：标题在第一行，步数、推箱数、用时与视野提示在第二行。棋盘下方单独放置有衬底的反馈和操作提示条，地图标题、地图提示和错误文字也增加衬底。棋盘上下留白随之调整，文字不再直接压在动态背景上。

箱子入位粒子的扩散半径由原来的 8–18 扩大到 24–54，恰好为原来的 3 倍；粒子数量和大小保留。

## CRT、脚下尘迹与音量追加调整

此前 CRT 是不采样底图的叠加层。现改为 Balatro `CRT.fs` 核心公式的 HLSL 移植，对背景、棋盘、文字、按钮和弹窗统一做真实画面采样。全场仅有一层 CRT，显示顺序低于转场遮罩、高于设置弹窗，避免弹窗再次叠加 CRT。保留原版曲面与边缘遮罩、RGB 扫描线、色差和噪声；加入平滑暗角，未启用故障条带与高成本泛光。

扫描线普通模式约每 6 个屏幕像素一条，低特效为 8 个像素，随窗口尺寸更新；强度由设置控制。根据最新反馈，曲率从 0.075 降到 0.0075，即上一版的 10%，保留已经认可的扫描线参数。强度归零时画面与输入均恢复无畸变；低特效减弱曲率和暗角，关闭噪声及色差采样。鼠标、拖动和触摸坐标同步映射到曲面后的实际控件位置。关卡编辑器不安装 CRT。

玩家尘迹改为中性灰，从当前显示位置下移 0.27 个格距的脚下位置产生，绘制在角色下面，短距离飘散后消失；不再从角色身体后方拉出长尾迹。根据后续反馈，粒子边长由 6/5/4 增至 12/10/8，灰度由 0.64 提至 0.74、透明度由 0.72 提至 0.90，持续时间由 0.20–0.25 秒延长至 0.32–0.38 秒，提高脚下辨识度。

音乐和音效的默认滑块值统一为 50%，音频通道的最大增益改为原来的 40%：滑块 50% 对应通道增益 0.20，100% 对应 0.40，0% 静音。按钮按下音效最初单独乘 1.5，根据最新反馈再乘 0.7（最终相对源片段增益 1.05）；悬停使用用户指定的 `card3.ogg`，文件哈希一致，音量调整为原先的 70%（片段增益 0.7）。悬停音效在进入按钮的当帧触发，不等待动效完成，也不在松开点击时重播。普通推箱音效 `crumple1` 提高 50%（片段增益 1.5）。后续用户保存的音量选择仍正常保留。

## 验证入口与证据

Unity 菜单 `Sokoban / Run Presentation Checks (Play Mode)` 执行逐帧回归，包括移动、原位刷新、箱子身份、撤销、重开、尺寸变化，实际按钮进入菜单/选关/游戏，列表悬停，以及暂停、地图、设置。

结果和截图位于 `docs/verification/presentation/`。检查脚本仅在 Unity 编辑器编译；实际关卡检查只推动第一关的一次箱子，然后撤销和重开，不写通关成绩。

最终验证：

- Unity 2022.3.51f1c1 / DX11 下三个表现 Shader 均为 supported，Shader 编译错误为 0。
- 控制台最终错误和警告为 0；规则/求解检查通过，包括 60 个随机关卡与穷举 Dijkstra 对照。
- 棋盘预制体、固定视野、大图跟随、完整地图检查通过。
- Play Mode 表现检查全部通过；转场记录显示每次新场景都从半径 -0.06 的全黑遮罩扩散至 1.12，实际截图可见圆形揭示过程。
- 入位粒子、列表悬停、实际第一关的行走/推箱/撤销/重开均通过；主菜单、选关、关卡、暂停、地图与设置截图已核对。
- 三个表现 Shader 已加入构建保留列表。本轮未重新构建独立程序。

追加调整已通过同一 Play Mode 回归：CRT 编译、曲面后的按钮命中、零强度恢复、低特效、设置弹窗不重复叠加、灰色脚下尘迹均通过，原移动与双向转场检查仍通过。最终截图更新于 `docs/verification/presentation/`。音量通道实测在滑块 0%、50%、100% 时分别为 0、0.20、0.40，记录在 `docs/verification/crt/audio-levels.txt`；设置截图显示音乐、音效均为 50%。
